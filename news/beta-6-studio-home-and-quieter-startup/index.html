    Beta 6 makes Studio Home clearer and startup quieter

    Game Maker became easier to reach from Studio Home, recent games gained a filter, and background account reads stopped prompting at startup.

    By NetVista Studio · Published 21 October 2026

    Recorded milestone
    29 September 2026
    Version / context
    1.4 Beta 6
    A retrospective of an earlier development milestone.

    This article was first published on 21 October 2026. The earlier milestone date describes the development record, not an earlier publication of this article.

    Find the workspace you need

    NetVista Studio 1.4 Beta 6 was publicly published on 29 September 2026. The source and download packages were prepared on 28 September, but that preparation date is not the release's publication date. This retrospective uses the public release timestamp so the sequence remains clear.

    On Mac, Game Maker gained its own illustrated launch card on Studio Home. The card opened the existing 2D and 3D game launcher; it was not the first arrival of Game Maker itself. A Games filter for recent projects and a responsive three-workspace card arrangement made the Home screen more useful as a place to resume or switch work.

    Keep background reads non-interactive

    Startup account restoration and reads of remembered sharing devices were changed so they no longer requested interactive Keychain access. That is a specific behaviour improvement: background checks should not unexpectedly ask for credential access simply because the app has opened.

    Saving a remembered account after a successful sign-in could still require Keychain access. Beta 6 did not remove the platform's security controls or promise that credential prompts could never appear. It separated deliberate saving from background restoration, keeping the latter non-interactive.

    A focused Mac refinement

    The Home layout and Keychain changes were Mac-specific. Windows and Linux continued to use the existing portable editor rather than receiving these native Mac interfaces. The Apple-silicon Mac download also remained ad-hoc signed and not Apple-notarized, with the possibility of a Gatekeeper warning. As with the earlier betas, users were asked to keep backups. Read this as a focused polish release, not evidence that every creative workspace had reached every operating system.
