    NetVista Studio's first public source and Mac beta

    The earliest public source already contained a native Mac editor. Its first packaged beta followed with timeline, colour and 3D tools.

    By NetVista Studio · Published 21 October 2026

    Recorded milestone
    10–13 August 2026
    Version / context
    1.1 Beta 1
    A retrospective of an earlier development milestone.

    This article was first published on 21 October 2026. The earlier milestone date describes the development record, not an earlier publication of this article.

    The earliest public record

    The first commit in NetVista Studio's public app repository is dated 10 August 2026. It contains the native macOS application, its build script and source for the timeline, colour, effects, export, 3D scene and local-sharing systems. This is the earliest development milestone we can verify publicly, not evidence that the app was created in a single day.

    That distinction matters because the initial upload already included a compiled application and substantial working source. The Mac interface used Cocoa and Apple's media and graphics frameworks, rather than presenting the editor inside a website wrapper.

    A downloadable beta follows

    NetVista Studio 1.1 Beta 1 was published on 13 August. It packaged multitrack video and audio editing, linked or independent audio movement, timeline preview, trimming, cutting, snapping and zoom. Colour grading, LUT import, effects, keyframes and 3D scenes were also listed in the release.

    Editable project saves and native movie export formed two separate parts of the workflow: keep the project to revise an edit, and export a movie when you want a playable result. Local device sharing was included, but this first release was a Mac app, not a standalone mobile editor.

    An early testing release

    The download required an Apple-silicon Mac running macOS 11 or newer. It was ad-hoc signed and not Apple-notarized, so downloaded copies could trigger Gatekeeper warnings. The release explicitly asked testers to expect incomplete features and protect important projects with backups. This retrospective records that historical release; the download page now offers the newer public beta.
