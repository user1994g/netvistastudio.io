    Development preview: native mobile creative workspaces after Beta 7

    Newer source adds native mobile creative workspaces and stronger checks. These development previews do not replace the public Beta 7 downloads.

    By NetVista Studio · Published 21 October 2026

    Recorded milestone
    20 October 2026
    Version / context
    Post-Beta 7 development
    Development preview—not a downloadable release.

    This story describes work in development as of the recorded milestone. It is not a statement that these features are included in the public beta download.

    Development work, not a new public beta

    The 20 October 2026 development report records work on the publicly pushed codex/native-workspace-test branch after the Beta 7 release. These previews are explicitly NOT included in the downloadable Beta 7 packages. They do not silently update those release assets or establish a new public version.

    By the recorded branch snapshot, 47 commits followed the released main branch. The report identifies exact build inputs and separates verified packages from later screenshot-only work. That distinction makes it possible to discuss progress without treating every source change or CI artifact as a supported public release.

    Apple and Android progress

    The newer Apple development package supports both iPhone and iPad, with independent native Video, Photos, Game Maker and 3D Editor workspaces. Photos, game and modelling reuse Mac engines. Combined phone/tablet simulator checks and stable-SDK CI cover workspace transitions and an actual movie-render and Files-cancellation workflow. Installation through AltStore still requires re-signing.

    Android development adds an independent Photos workspace alongside Video. The recorded build passed 44 instrumentation methods on each phone and tablet profile, including photo authoring, camera-image orientation, compositing comparisons and video preview/export. Its package retains the established signing identity. These are results for specific development inputs, not proof that every device or workflow is ready.

    What still needs to happen

    Full desktop parity and physical-device acceptance remain open. Apple video still lacks complete multitrack/audio placement, ordered advanced effect stacks, node grading and 8K/16K delivery. Android Game Maker and 3D authoring are not yet ported, and several advanced photo tools remain absent.

    A separate screenshot-evidence run encountered emulator or system-launcher interruptions and was not represented as passed. It must not be confused with the passing packaged build. Real installation, account sign-in and physical-device codec or memory coverage remain further gates. For the public download, continue to use Beta 7 and its narrower published feature list.
