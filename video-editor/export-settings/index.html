NetVista Studio/Video Editor/Export settings

DELIVERY / MAC VIDEO EDITING GUIDE

Export MP4
and 4K video.

Turn the edited timeline into a movie with the resolution, codec, frame rate and sound you need. Start with a short export before rendering a longer sequence.

By NetVista Studio · Updated 3 October 2026 · macOS · 1.4 Beta 6

In this guide
  1. Prepare the timeline
  2. Choose MP4 and resolution
  3. Set frame rate and audio
  4. Confirm and save the movie
  5. Check the export and its limits

1. Prepare your timeline for export

These steps use the native Mac Export workspace in NetVista Studio 1.4 Beta 6. Windows and Linux use a different FFmpeg workflow. The video editor overview explains the platform differences; the first-project guide covers building a sequence.

Play the timeline first. Confirm clip order, trims and audio, and apply any previewed effects or colour changes you want to keep. Save the editable .netvistastudio project. That project lets you revise the edit later; an exported MP4 or MOV is a movie, not a replacement for the project.

2. Choose MP4, a codec and output resolution

Open Export. For a small first test, choose 1080p HD, Format MP4 and Video codec H.264. To make a 3840 × 2160 movie, choose 4K Ultra HD instead. Raising the output resolution does not restore detail missing from lower-resolution source footage.

MP4 and MOV are file containers; H.264, HEVC (H.265) and Apple ProRes 422 are video codec choices. Automatic asks the editor to select an available encoder. The app checks system capabilities, and an unavailable codec can fall back to a compatible one. A selected option is not a guarantee that every Mac can encode every size.

Custom size allows another frame shape. The native engine uses even dimensions and caps output at 15360 × 8640. Use a short test when changing aspect ratio so you can inspect the composition.

3. Set frame rate and include the timeline audio

Choose 24, 25, 30 or 60 fps to suit the footage and intended delivery. A different output frame rate is not a substitute for checking motion in the resulting movie. Keep Include timeline audio enabled when you want the sequence's sound; turning it off creates video-only output.

Fast-start playback prepares the file for network playback where supported. It does not upload or publish your movie. Review the output summary and any encoder capability message before starting.

4. Confirm the settings and save the movie

Press Export Movie…. The Export movie confirmation shows the delivery settings together, including frame rate. Review them, then choose Continue to Save. Pick the filename and folder in the save window; Downloads is the default, but you can choose another destination.

The progress panel remains available during rendering and includes Cancel Export. Export uses a staging file, so cancellation or encoder failure does not replace an existing movie at the chosen destination with a partial render.

5. Check picture, sound and high-resolution limits

Open the completed movie and watch it from beginning to end. Check joins, empty gaps, layered footage, colour, keyframe timing and audio. If sound is missing, check Include timeline audio and that the sequence contains audible audio clips. If media cannot be read, restore access to the source files and retry a short sequence.

8K and 16K need considerably more resources. The 16K preset switches to MOV and Apple ProRes 422 and disables fast-start; available memory and encoder support still limit success. Do not assume an export will work simply because a preset appears.

For targeted editing help, use the zoom and fade keyframe guide or the colour grading and LUT guide. Keep the project and original footage backed up during the beta.
