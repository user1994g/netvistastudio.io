    COLOUR / MAC VIDEO EDITING GUIDE

    Import .cube LUTs
    and grade video.

    Apply an imported look, dial back its strength, or build an editable grade from nodes. Keep the correction in your project and export a reusable node LUT when needed.

    By NetVista Studio · Updated 3 October 2026 · macOS · 1.4 Beta 6

    In this guide
    1. Choose your shot and LUT
    2. Import and mix a .cube LUT
    3. Build an editable node grade
    4. Export the node stack as a LUT
    5. Save and check the result

    1. Choose a shot and a compatible LUT

    This guide covers the Mac colour workspace in NetVista Studio 1.4 Beta 6, not the Windows/Linux interface. Select a timeline video clip and open Color. The getting-started guide covers importing footage and making your first sequence.

    A LUT maps input colours to output colours. Use one intended for your footage and the look you need; importing a file does not automatically identify a camera's log format. NetVista accepts 3D .cube LUTs and rejects 1D LUT files. Keep your source footage available throughout the edit.

    2. Import a .cube LUT and adjust its intensity

    Open the LUT tab and choose Import .cube…. Select the file, then use Imported LUT mix to vary its strength from 0 to 100%. Start with a lower mix if the full look overwhelms the shot. Inspect a representative frame and compare using Bypass grade.

    Choose Apply to Selected Clips to commit the look. Revert Preview returns to the saved grade; Remove imported LUT clears the LUT from the working controls, so apply again to keep that removal. These colour changes do not overwrite your original video file.

    3. Build a grade with editable nodes

    For a grade you can revise, open Nodes and press +. Select the new node, name it, and adjust its Exposure, Contrast or Saturation. Nodes run from top to bottom. Use the arrows to reorder them, Enabled to compare one correction, and Mix / opacity to reduce its contribution.

    In Primaries, base Exposure, Contrast, Saturation, Temperature, Tint and Vibrance are separate from the node controls. The Lift, Gamma and Gain wheels belong to the selected node: choose or add one before using them. Curves also belong to that node, including Master, RGB and hue/luma curves.

    Keep an initial correction simple before adding a stronger creative look. The Scopes tab offers waveform, parade, histogram and vectorscope views for examining the current frame. Preview several parts of the shot, then commit with Apply to Selected Clips.

    4. Export a reusable node-stack LUT

    In LUT, choose an Export size of 17³, 33³ or 65³, then press Export current nodes…. Choose a name and destination for the .cube file. The size describes the colour table's sampling grid, not the resolution of your video.

    This export contains the node stack only. It does not include the separate base Primaries adjustments or an imported LUT, and it is not an editable copy of the nodes. Keep the native project when you need to revise their individual settings. Test the exported LUT on another shot before using it throughout a sequence.

    5. Save the project and verify the movie

    After applying the grade, save your .netvistastudio project. Imported LUT data is embedded in that save, so the look can survive moving the original .cube file; the project's source video still needs to remain accessible. Keep backups while using the beta.

    Follow the MP4 and 4K export settings guide for a short delivery test. For changes in a shot's scale or opacity over time, see the separate zoom and fade keyframes guide.
